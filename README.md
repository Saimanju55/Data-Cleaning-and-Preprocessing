# Data Analyst Internship - Task 1

## Dataset
Medical Appointment No Shows

## Objective
Clean and preprocess raw dataset by handling:
- Missing values
- Duplicate records
- Inconsistent formats
- Incorrect data types

## Steps Performed
- Checked for missing values using isnull()
- Removed duplicate rows
- Standardized column names
- Converted ScheduledDay and AppointmentDay to datetime
- Removed negative age values
- Converted No-show column into binary (0 = Show, 1 = No Show)
- Created waiting_days feature

## Final Output
Cleaned dataset ready for analysis and modeling.
